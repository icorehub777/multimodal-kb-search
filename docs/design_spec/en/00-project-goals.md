# Project Goals

[繁體中文](../00-%E5%B0%88%E6%A1%88%E7%9B%AE%E6%A8%99.md) | English

The goal is to build an enterprise document search and reading assistant centered on Codex Agent. Users can search with natural-language descriptions or images, and Agent can locate relevant content in a Google Workspace document repository. In addition to understanding, analyzing, and responding from matched document pages, Agent can further process the retrieved documents and apply their content to other tasks, helping users obtain and use the information they need more thoroughly and efficiently.

The system supports both Google Drive keyword search and multimodal similarity search using an Alibaba Cloud multimodal embedding model and Qdrant. It returns to Codex Agent only documents that the current user is authorized to access.
