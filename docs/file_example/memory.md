# Agent Memory

> 本文件是 `agent_runtime/memory.md` 的範本，用於 Agent 在不同 session 之間接手 KBSearch 查詢任務。
> 實際查詢結果、下載檔案、頁面 PNG、關鍵字結果清單、向量結果清單與分析草稿，仍以各次任務資料夾內的內容為準。
> 請保持精簡，只記錄會影響後續 Agent 判斷與接手的資訊；不要記錄流水帳，也不要貼上大量查詢結果或文件原文。

## 注意事項

> 填寫指引：
> 記錄跨 session 接手時必須先知道的限制、規則、環境狀態或專案慣例。
> 只保留會影響後續 Agent 操作或判斷的事項。
> 不重複記錄已在 `AGENTS.md` 或設計文件中完整說明、且不會因實際運作狀態改變而更新的通用規則。

## 最近查詢與處理紀錄

> 填寫指引：
> 每筆只記錄近期已完成或已中止的重要查詢任務，並指向細節所在資料夾。
> 不記錄開過哪些檔案、嘗試過但沒有結論的指令、小修文字或中間過程。
> 建議最多保留 5 到 10 筆；更舊內容應濃縮或移除。
> 格式建議：`YYYY-MM-DD HH:mm：完成 <查詢名稱>；結果見 <相對路徑>；結論摘要：<一句話>。`
